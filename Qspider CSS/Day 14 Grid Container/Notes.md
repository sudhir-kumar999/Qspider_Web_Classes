# Grid : it is 2D layout module

Grid Terminology:- 
Grid lines show on scaler website
Grid Track
Grid cells
Grid areas

# grid container properties
display:____
grid :-generate block level grid
inline-grid:-generate inline level grid

# grid-template-columns_____  ______  _______
                      size of column 1  size of column2 size of column 3
                      it is used create columns inside grid


# grid-template-rows:____  _______  _______
              size of row 1  size of row 2  size of row 3
               it is used to create number of rows inside grid

# grid-template:___________  _________
          grid template rows   grid template columns

it is shorthand property of grid template rows and grid template columns

# gap: _____  ______;
    row gap  column gap

it is used to create gutters

# justify-items:________;
 to align items in row (horizontally)

# align-items:_______;
 to align items in columns (vertically)

#  place-item:_____ ______;
            align-items  justify-items
            it is the shorthand property of align items and justify items

# justify-content:___________;
it is used to align the grid horizontally inside grid container 

# align-content:_________;
it is used to align the grid vertically inside the grid container

# place-content:___________ _________;
        align-content   justify-content
        it is the shorthand property of align content and justify content

# grid-auto-flow:_______;
 it is used to define how the auto placement algorithm works

 # grid-auto-rows:______;
 to define the size of any auto generated row

 # grid-auto-columns:_______;
  to define the size of any auto generated columns
